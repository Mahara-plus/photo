# تحدّي صورة 🧩
تطبيق لعبة عربية يعمل محليًا على نفس الجهاز، مع 200 لغز موزعة على أربع فئات.
- 50 مثلًا عربيًا، 50 أغنية عربية، 50 مسلسلًا عربيًا، 50 مدينة عربية وعالمية.
- أنماط: اختبر معلوماتك، تيم ضد تيم (حتى 4 أعضاء لكل فريق)، واحد ضد واحد.
- اختيار الفئة وعدد الأسئلة من 1 إلى 50، إظهار الحل ثم تحديد صاحب النقطة أو «ما حدا جاوب».
- واجهة عربية فاتحة، شعار تطبيق، ومشاهد رسومية محلية بطابع سينمائي تعمل دون إنترنت.

## تشغيل الويب
افتح `index.html` أو ارفع المشروع إلى GitHub Pages.

## بناء APK
افتح مجلد `android` في Android Studio ثم Build > Build APK(s).
أو ارفع المشروع إلى GitHub وافتح Actions وشغّل workflow **Build Android APK** ثم نزّل artifact `tahaddi-soura-debug-apk`.
الـAPK الناتج Debug للتجربة؛ النشر الرسمي يحتاج إعداد توقيع Release.

## ملاحظة عن الصور
المشاهد المرفقة رسومات محلية بطابع فوتوغرافي/سينمائي لكل فئة وليست 200 صورة فوتوغرافية مستقلة؛ محتوى التلميح نفسه يتغير مع كل سؤال.
